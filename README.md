# Playlist Bridge Support Website

Public help centre and product information site for Playlist Bridge for Plex.

## Website
Once GitHub Pages is enabled, the site will be available at:

https://andrewc70-lang.github.io/playlist-bridge-support/

## Pages
- Home: `/`
- Help & support: `/support/`
- Privacy policy: `/privacy/`

## Publishing
This repository is configured for a static GitHub Pages site. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
